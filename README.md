# Style Canvas AR

AI Virtual Outfit Stylist (AR) – Full Stack App Prompt

You are an expert team of UI/UX designers, AR engineers, AI engineers, and full-stack developers.

Build a premium production-ready web and mobile application that allows users to virtually try clothing and accessories using Augmented Reality (AR), AI body detection, and outfit recommendation.

The design should feel like Apple + Zara + Pinterest + Instagram combined.

Use modern UI, smooth animations, glassmorphism, premium typography, and luxury aesthetics.

Project Name

StyleAR
"See Your Style Before You Wear It"

Main Objective

Allow users to:

• Scan themselves using their phone camera
• Scan clothes or upload clothing photos
• Build a digital wardrobe
• Virtually wear clothes in AR
• Try accessories like shoes, watches, sunglasses, bags, jewelry, hats, etc.
• Receive AI fashion recommendations
• Save outfits
• Share outfits
